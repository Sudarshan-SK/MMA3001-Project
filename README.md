# Rocket Recovery Descent Simulation and Landing Dispersion

MMA3001 individual project: Sudarshan Shorna Kumar (33856249)

This project simulates the descent of a dual-deployment high powered rocket from apogee to the ground. It predicts the landing point and a 95 % landing ellipse. The model is validated against flight data from a Monash High Powered Rocketry's rocket launch, recorded by the team's Galileo Flight Computer (GFC).

## 1. Engineering problem

The team needs to predict where a rocket will land after it reaches apogee. This is used to check that the landing point lies inside the range-safety boundary, to choose the main-deployment altitude, and to plan recovery. This project builds a transparent descent model, tests it against a real flight, and adds a Monte Carlo estimate of the landing uncertainty.

**Scope:** descent only, from apogee to touchdown, under the drogue and then the mains parachute.

**Main assumptions:**
- the rocket and parachute are one point mass;
- drag is quasi-steady, using the known drag coefficients;
- the main parachute opens instantaneously at the deployment altitude;
- the atmosphere is the ISA troposphere, anchored at the pad;
- the wind is horizontal and steady in time;
- the Earth is flat and non-rotating, with g = 9.81 m/s².

## 2. Inputs and outputs

| Input | Units | Notes |
| --- | --- | --- |
| Descent mass | kg | must be > 0 |
| Parachute diameter and Cd | m, dimensionless | must be > 0 |
| Main deployment altitude | m above the pad | must be ≥ 0 and below apogee |
| Pad pressure and temperature | Pa, K | defines the ISA atmosphere |
| Wind | m/s | constant, power law, or a table of height against east/north components |
| Initial state | m, m/s | (x, y, z, vx, vy, vz): x east, y north, z up |
| GFC flight data | CSV | barometer, accelerometer, GPS and flight events in `data/processed/` |

| Output | Units |
| --- | --- |
| State history, main deployment time and landing time | s, m, m/s |
| Landing point, east and north of the start point | m |
| 95 % landing ellipse (semi-axes and bearing) | m, degrees |

Invalid physical inputs raise `ValueError`, and missing data files raise `FileNotFoundError`.

## 3. Repository structure

```
src/            simulation package (one job per module)
  constants.py    physical constants
  atmosphere.py   ISA and constant-density atmospheres
  wind.py         constant, power-law and profile wind models
  integrators.py  hand-written Euler and RK4
  analytical.py   exact solutions used for verification
  descent.py      descent ODE and solve_ivp with deployment and landing events
  flightdata.py   loading and processing the GFC logs
  drift.py        hand-calculation drift baseline and GPS-derived wind
  uncertainty.py  vectorised Monte Carlo and landing ellipse
tests/          pytest test suite and test_report.html
notebooks/      analysis.py (produces every figure and result) and supporting studies
data/processed/ processed GFC flight data
figures/        figures used in the report
docs/           HTML documentation generated by pdoc (open docs/index.html)
```

```bash
# Regenerate the HTML documentation
pdoc ./src -o ./docs
```

## 5. Methods

- **Descent model:** m dv/dt = −mg ẑ − ½ρ(z) Cd S |v_rel| v_rel, with v_rel = v − w(z). The model is solved with SciPy `solve_ivp`. A terminal event stops the integration at main deployment, and it restarts with the main's drag area, so no step crosses the discontinuity.
- **Verification:** hand-written Euler and RK4 converge at observed orders 1.00 and 4.03 against the exact solution.
- **Flight data processing:** timestamps are unwrapped, and altitude is recomputed from pressure.
- **Uncertainty:** a vectorised fixed-step RK4 Monte Carlo gives a 95 % landing ellipse.

## 6. Limitations

- Validation uses one flight only.
- The wind profile is derived from the same GPS track it is tested against, so the landing check does not test a wind forecast.
- The manufacturer's Cd for the main appears to be overstated: the model falls about 15 % too slowly under the main.
- The model does not represent parachute inflation or pendulum motion.
